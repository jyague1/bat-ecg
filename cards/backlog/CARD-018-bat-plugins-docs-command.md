# CARD-018: `bat plugins docs` Command

## Goal

Implement the `bat plugins docs` command that generates Markdown documentation for all discovered plugin modules.

## Context

BAT generates plugin documentation automatically from module schemas, docstrings, examples, and citations. This allows plugin authors to write their schema once and get documentation for free.

Documentation output is Markdown in v1.

## Command

```bash
bat plugins docs
```

## Output

By default, prints Markdown to stdout. Optionally writes to a file:

```bash
bat plugins docs > docs/plugins.md
```

## Source of documentation fields

Each field in the Markdown comes from the module schema (CARD-007):

| Markdown field | Schema source |
|----------------|---------------|
| Module name | `Meta.name` |
| Description | `Meta.description` |
| Source/version | Plugin registry |
| Citations | `Meta.citations` |
| Parameters | `Params` Pydantic model fields |
| Inputs | `Inputs` Pydantic model fields |
| Outputs | `Outputs` Pydantic model fields |
| Examples | `Meta.examples` |

## Tests

- Output is valid Markdown
- All modules appear in the output
- Citations appear correctly (including `none` as "(none)")
- Parameter table includes type, required, default, and description
- Modules with examples include an example YAML block
- Modules are grouped by collection namespace

## Acceptance criteria

- `bat plugins docs` outputs valid Markdown to stdout
- All schema fields are represented in the output
- Citations are always shown (the field is required)
- Examples are included when defined in the schema
- Modules are grouped by collection with a heading per collection
